# 4(b) Diabetes One-Sample Z-Test

## Overview

This project performs a **One-Sample Z-Test** on a dummy diabetes dataset.

The test checks whether the mean glucose level is significantly different from **100**.

## Files

```text
4b_diabetes_ztest_project/
├── 4b_diabetes_ztest.py
├── diabetes_data.csv
├── requirements.txt
└── README.md
```

## Libraries

- Pandas - Creates and handles the DataFrame
- Statsmodels - Performs the One-Sample Z-Test

## Dataset Columns

- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age
- Outcome

## Hypotheses

**Null Hypothesis (H0):**
```text
Mean Glucose = 100
```

**Alternative Hypothesis (H1):**
```text
Mean Glucose ≠ 100
```

## Significance Level

```text
Alpha = 0.05
```

If the p-value is less than 0.05, the null hypothesis is rejected.
